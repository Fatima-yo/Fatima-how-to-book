Basic SCP Syntax - downloading
------------------------------

from server terminal (as root):

sudo cp '/etc/nginx/sites-enabled/tac' '/home/cameron/tac'

sudo chown -c cameron ./mailing.db.bak-20260311-002548
sudo chgrp -c cameron ./mailing.db.bak-20260311-002548
