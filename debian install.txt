
generate bootable usb
---------------------
dd if=debian-live-8.6.0-amd64-xfce-desktop.iso of=/dev/sdb bs=4M; sync


install
---------------------
boot from usb

iwlwifi-3160-9.ucode

download from:
https://git.kernel.org/cgit/linux/kernel/git/iwlwifi/linux-firmware.git/plain/iwlwifi-3160-9.ucode

copy:
cp iwlwifi-3160-15.ucode /lib/firmware/

load:
modprobe -r iwlwifi ; modprobe iwlwifi

also may require:
iwlwifi-3160-8.ucode
rtl_nic/rtl8106e-1.fw
