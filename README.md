
Fatima's Linux How-to Book

Welcome.
You may think (or someone may have tell you) that Linux is difficult to use.
That is not true.
Using Linux is similar to using Mac or Linux.

But if you want to be an advanced user, then of course you need to learn a few things.
This book explain some of those things.

The idea for this book is to make things easy for beginners.
This book is based on notes that I have been taken for 13 years while doing things, because I have very bad memory :-)
